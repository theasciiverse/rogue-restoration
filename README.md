# rogue-restoration

## Play

With [av](https://asciiverse.sh), the Asciiverse client:

Each game installs on its own:

| Game | With av | From a release archive |
|---|---|---|
| Advanced Rogue 5.8 | `av install arogue` | `./arogue` |
| Rogue 3.6 | `av install rogue36` | `./rogue36` |
| Rogue 5.2 | `av install rogue52` | `./rogue52` |
| Super-Rogue | `av install srogue` | `./srogue` |
| UltraRogue | `av install urogue` | `./urogue` |
| XRogue | `av install xrogue` | `./xrogue` |

Start one with `av play <name>`, or download its archive for your system from
this repository's Releases and run it from there.
