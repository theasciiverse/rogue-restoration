# Held from release

Archive lists moved here so `package.sh` does not pack these games into
releases. Super-Rogue, Advanced Rogue and UltraRogue have licences that
forbid derived products from using those names without prior written
permission. Our patched builds are derived products, so they stay out of
releases until permission is given (asked of Nicholas J. Kisseberth after the
Asciiverse launch) or they are renamed. Move a list back into
`asciiverse/archive/` to release that game again. They still build.
